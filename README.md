## 🧩 Featured projects

### 🛡️ DataGuard AI
Python data-quality toolkit combining deterministic validation checks with AI-assisted exploration of findings.

- Checks for missing values, duplicates, type mismatches, range violations, and statistical outliers
- Includes a LangGraph analysis workflow and MCP tools
- **21 passing unit tests**

### 🏦 Smart Banking Analytics
A machine-learning study of loan approval patterns using a **4,269-record** dataset.

- Data preparation, exploratory analysis, and a Random Forest model
- 80/20 train-test split; approximately **97.7% reported model accuracy**
- Analytical project only; not used for real lending decisions

### 🛍️ Retail Sales Analytics
A personal project exploring a practical data-to-insight workflow.

- Python processing, MySQL data structure, and SQL analysis
- Flask interface for presenting visual insights
- No business outcome or sales figures are claimed

## 🚀 Run it locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

The output is generated in `dist/`. The current portfolio does not need environment variables; its contact section uses direct email links.
